# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it
responsibly and privately. Do **not** open a public GitHub issue for security
vulnerabilities.

To report a vulnerability, please use one of the following channels:

- **GitHub Private Vulnerability Reporting**: Use the "Report a vulnerability"
  button under the Security tab of this repository.
- **Email**: Contact KJC InfoTech Limited via the maintainer's listed GitHub
  profile contact details.

Please include as much of the following information as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Affected versions, commit SHA, or branch
- Any suggested remediation, if known

## Response Process

- We will acknowledge receipt of your report within a reasonable timeframe.
- We will investigate and aim to provide a status update as we assess severity
  and develop a fix.
- We ask that you give us a reasonable opportunity to address the issue before
  any public disclosure.

## Scope

This repository, DataObs, is proprietary software owned by KJC InfoTech
Limited. Source code is visible for evaluation and review purposes, but is
not open source. See the [LICENSE](./LICENSE) file for full usage terms.

Security reports are welcomed for:

- Vulnerabilities in code contained within this repository
- Vulnerabilities in configuration, workflows, or dependency management
  defined within this repository

Out of scope:

- Vulnerabilities in third-party dependencies (please report upstream)
- Social engineering, physical security, or denial-of-service testing against
  any hosted infrastructure

## Supported Versions

As this project is under active development and has not yet reached a
tagged production release, only the latest `main` branch is supported for
security fixes.

Thank you for helping keep this project and its users secure.
