# API v1

Canonical route groups are `/api/v1/tenants`, `/api/v1/sources`, `/api/v1/integrations`, `/api/v1/collectors`, `/api/v1/scanners`, `/api/v1/scan-policies`, `/api/v1/assets`, `/api/v1/monitors`, `/api/v1/incidents`, `/api/v1/lineage`, `/api/v1/pillars`, and `/api/v1/migrations`. `/livez` reports process liveness. `/readyz` validates settings and required Elasticsearch migrations. `/health` is retained with deprecation headers.
