# Console information architecture v2

The Team 5 shell organises operator intent into six workspaces: Home, Observe, Investigate, Respond, Integrate, and Admin. A workspace rail is level one, registry-backed capability links are level two, and registry-backed child routes are contextual level three. Detail routes never become permanent navigation. Stable URLs remain unchanged.

## Route map

- **Home:** Command Center, Activity, Operational Dashboards.
- **Observe:** Data Flow, Assets, Data Products, Data Contracts, Pathways, Streams, Data Quality, Jobs, and Lineage.
- **Investigate:** Global Search and Investigation Workspace. Stream/change intelligence remains contextual to its owning capability.
- **Respond:** Incidents and Event Storms.
- **Integrate:** Integrations and onboarding.
- **Admin:** Administration, access, system information, preferences, and diagnostics.

The complete audited mapping is maintained in the Team 5 navigation audit.
