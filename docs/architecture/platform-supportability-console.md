# Platform supportability Console

The Console adds two permission-isolated child routes beneath Platform Operations. Six independent, bounded GET requests use two-second section deadlines, deduplication, abort propagation and partial settlement. The view has a five-second overall deadline and manual refresh. A failed section does not erase successful evidence.

The browser renders typed, approved fields. It does not read operational YAML, run commands, generate bundles, execute remediation or dump arbitrary JSON. Team 0 remains the semantic and data owner.

Runtime health describes current execution. Supportability describes whether bounded operating prerequisites are evidenced. Operational readiness is Team 0's gate result. Release readiness is its separate release decision. Certification requires independent evidence. None implies another.
