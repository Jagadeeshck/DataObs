# Unified investigation workspace

The lazy `/investigate` route orchestrates explicit, statically registered providers. Providers run in parallel with a 2-second individual timeout and 4-second global deadline; failures remain isolated and incremental snapshots remain usable. The timeline is capped at 100 items, each provider at 25. Established relationships are depth one and capped at 50 nodes/100 edges. The table is the accessible authoritative graph representation in v1.

Temporal proximity never establishes causality. The workspace sends users to capability-owned pages for deep analysis and mutation workflows.
