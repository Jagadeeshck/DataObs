# Upgrade compatibility presentation contract

Only allowlisted fields from the typed compatibility and readiness responses are rendered. `unknown` is never labelled supported; `compatible_but_unvalidated` remains unvalidated; `blocked` is not softened; and `NO_GO` remains `NO_GO`. Stale evidence must be labelled as a previous result and cannot become a current pass. Migration terminals, intermediate hops, deprecation applicability, and rollback procedures are never derived in the browser.

Compatibility describes an independently assessed property. Upgrade readiness describes whether authoritative upgrade gates passed. Operational readiness describes service operation. Release decision is approval governance. Certification is captured proof. None implies another.
