# Visual evidence semantics

Evidence kind (`measured`, `estimated`, `inferred`, `forecast`) is independent of availability (`available`, `partial`, `stale`, `missing`, `unknown`, `unavailable`) and health. Forecast receives its own label/style/horizon; expected lower/upper bounds are not thresholds. Missing is “No observation,” never zero. Anomaly score is backend evidence, not health. Display impact (for example **Impact 78**) separately from confidence (for example **Confidence Medium**). Temporal proximity/correlation is not causality. Healthy is not certified; configured is not healthy.
