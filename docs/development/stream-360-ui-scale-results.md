# Stream 360 UI scale results

No scale result is claimed in this checkout. The target fixture is 10,000 topics, 100,000 partitions, 20,000 groups, one million current assignments, and twelve months of bounded history. API p50/p95, payload size, route load, browser memory and bundle evidence must be recorded from the product stack before the draft gate can be lifted.

The implemented inventory contract caps pages at 200 rows, uses server-side `search_after`, and exposes an integrity-protected cursor. Console Stream routes are code-split. Heatmap aggregation and virtualization remain blocking work.
