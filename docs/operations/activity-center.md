# Operating the Activity Center

Use All Activity for recent events, Needs Attention for explicit policy matches, and Watchlist for exact canonical entity references. Filters are bounded and global time selection applies. **Mark as seen** and **Mark visible as seen** update session-only browser state; they do not acknowledge or resolve anything. Open routes to the authoritative capability. Investigate preserves entity, time range, source and return route.

“No activity observed” means every invoked source succeeded. “Activity is partial” means one or more invoked sources failed or timed out. Access-limited messaging does not disclose restricted resources. Refresh uses the Console global refresh control; auto-refresh never runs below 30 seconds and respects Page Visibility.
