# Anomaly investigation

Read observed value, expected range, cohort/fallback reason, generation, method, formula, eligible sample count, exclusions, normalized deviation, score and confidence together. Zero is measured evidence; missing is not zero. Cold start, stale evidence and source unavailability are not healthy results.

Review nearby schema, contract, deployment and job/run evidence as correlated context only. An anomaly is not a root cause. Use bounded asynchronous lineage impact for downstream context and observe truncation/confidence. Resolve findings through the canonical finding/incident workflow. A repeated consistent change may be a regime candidate, but requires a human recommendation decision.
