# Console visualization performance

Elastic Charts and Cytoscape should remain outside the initial shell where route composition permits; Cytoscape is dynamically imported. Series reject more than 2,000 points (dashboard adapters should request at most 500); topology rejects more than 100 nodes or 200 edges. Larger authoritative views require explicit capability support and benchmark evidence. Do not silently client-downsample. Avoid rendering collapsed/off-screen charts. Reduced-motion CSS disables transitions and graph layouts use `animate: false`.
