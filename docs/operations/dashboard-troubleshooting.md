# Dashboard troubleshooting

- **Permission message:** the provider was not invoked and no previous counts are shown.
- **Unavailable/not configured:** configure the capability or use its authoritative page; the saved layout is retained.
- **Partial/stale:** previously visible evidence must be labelled; refresh does not turn missing evidence into zero.
- **Private view missing:** browser storage may have been cleared or corrupt and safely reset.
- **Watchlist cleared:** tenant/environment changed or the browser session ended; this is intentional.
- **One widget fails:** use its retry/global refresh; the rest of the dashboard remains usable.

No raw query editors, mutation actions, iframe/custom widgets, durable watchlists or dashboard sharing exist in v1.
