# Authoring data SLOs

Select a canonical asset or job, an explicit SLI family and evidence sources, objective, bounded window, granularity, missing-evidence policy, and exclusions. Review the visible formula, create a draft, optionally run a clearly labelled bounded historical simulation, then activate. A 100% objective is permitted only with its zero-budget warning. Material updates require `If-Match`, actor, and a bounded reason and create a revision.
