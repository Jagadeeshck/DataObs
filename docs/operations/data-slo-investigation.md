# Investigating data SLOs

Start with state, SLI, remaining budget, short/long burn, coverage, and confidence. Inspect bad, unknown, and excluded counts separately. Follow canonical evidence references to monitors, jobs, contracts, dbt, or schema intelligence; anomaly state is context and is not itself a violation. Exclusions remain visible with actor, reason, source, and time bounds. Use lineage impact asynchronously to identify downstream assets, products, and owners.
