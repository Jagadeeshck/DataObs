# Integration onboarding

Beta 1 saves only onboarding step and selected goal IDs under `dataobs.console.onboarding.v1`. Recommendations are deterministic category unions for the selected goals. Integration support and setup details must come from Team 4 metadata.

The browser must submit only backend-managed credential or external secret-manager reference identifiers when a future configuration contract is approved. Never enter or persist resolved secrets, tokens or passwords in URLs, local storage, logs, fixtures or screenshots. Clearing site data removes local progress.
