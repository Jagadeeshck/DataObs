# Investigating lineage impact

1. Confirm status, freshness, warnings, cycles, and truncation before interpreting counts.
2. Start with direct column paths, then direct dataset paths, then transitive paths.
3. Review the returned formula, component values, and missing evidence.
4. Use quality findings, reliability state, and incidents as context only; temporal correlation is not causation.
5. Open canonical Asset 360, Job, Quality, and Data Product pages for authoritative details.

No observed downstream entity is not proof that no dependency exists. Never describe structural exposure as confirmed breakage.
