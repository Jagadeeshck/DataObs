# Messaging console troubleshooting

1. Confirm tenant, environment, and time context.
2. Inspect the provider card's configuration, collection, runtime, freshness, latest observation, coverage, and limitations.
3. “Messaging evidence is partial” means one or more provider sources are stale/unavailable or the provider request failed; other evidence remains usable.
4. “No observation” is distinct from measured zero. “Not applicable” means the capability is semantically unsupported.
5. Use Integrations for setup, Investigation for bounded evidence, and Pathways only where authoritative links exist.
