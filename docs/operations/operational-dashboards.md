# Operating dashboards

Open **Operational Dashboards** from Command Center or `/dashboards`. Choose one of six built-ins, or clone one into a private browser view. The header's trusted tenant, environment, time range, manual refresh and visibility-aware auto-refresh remain authoritative. Enter edit mode to add/remove widgets or use labelled keyboard-friendly move/resize buttons. Reset restores the template. Open details uses the capability's canonical route; Investigate opens the Investigation Workspace. Watchlist storage is session-scoped, limited to 25 and cleared whenever trusted tenant/environment changes.

Rollback removes the two dashboard routes and lazy feature package; it requires no backend or migration rollback.
