# Operational handover checklist

Do not mark an item complete without referenced evidence.

- [ ] Record release SHA, application/chart version and release decision.
- [ ] Record known limitations and open known-issue identifiers.
- [ ] Verify registry terminal, applied terminal, pending count and collisions.
- [ ] Verify last backup and destructive disposable restore evidence.
- [ ] Confirm rollback policy without claiming unsupported upgrade paths.
- [ ] Confirm monitors, alerts and evidence freshness.
- [ ] Assign primary/secondary team ownership and escalation reason codes.
- [ ] Validate SEV1/SEV2 runbook coverage.
- [ ] Exercise bounded diagnostics and preserve request IDs.
- [ ] Validate support-bundle v2 allowlist, limits, redaction and checksums.
