# Version upgrade Console troubleshooting

If a section is unavailable, refresh once and record the request through approved observability rather than repeatedly polling. A partial response is useful evidence but is not a pass. Confirm the target is accepted by the Team 0 endpoint. For migration graph, terminal, Helm consistency, recovery, or deployment procedures, use approved release tooling and runbooks; the Console cannot execute them. Escalate persistent permission failures to the platform operator access owner.
