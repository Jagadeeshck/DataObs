# Workflow troubleshooting

For `not_configured`, verify feature/runtime readiness; never substitute a generic executor. For a stale preview/approval, refresh the incident and create a new exact request. For lease conflict, let the current fence owner finish. For an expired lease with an operation reference, call the allowlisted lookup before reconciliation. Missing verification evidence remains pending/failed, not successful.


For Kibana 9.4.2, distinguish `feature_disabled`, `license_unavailable`, `not_configured`, `forbidden`, `unreachable`, and `unsupported_version`. Never retry an uncertain run; reconcile its exact execution identity. Unknown provider status is `provider_status_unknown`. See [Elastic Workflows runtime](elastic-workflows-runtime.md).
