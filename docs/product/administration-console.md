# Administration and Access Management Console v1

v1 provides a coherent Administration overview, current-user access explanation, tenant-bounded binding inventory/detail, review-first creation, confirmed revocation, conflict-safe transport foundations, dedicated last-administrator messaging, honest audit unavailability, safe system information, and non-sensitive preferences.

Unsupported features include identity provisioning/search, password/MFA/group management, impersonation, token tools, custom roles/permissions, bulk or wildcard grants, cross-tenant super-admin UX, credentials/API keys, direct Elasticsearch/Kubernetes/Helm administration, and audit deletion. Running and healthy states are never represented as certified.
