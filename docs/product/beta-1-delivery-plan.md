# Beta 1 delivery plan

This is a plan, not a statement that Beta 1 is delivered.

| Team | Parallel wave 1 | Parallel wave 2 |
|---|---|---|
| Team 0 | Beta deployment packaging | Beta security hardening |
| Team 1 | Connector and Schema 360 | Pathway Explorer Console |
| Team 2 | Data Quality Console | Job/Run Reliability |
| Team 3 | Incident Workbench | Incident Correlation and Flood Control |
| Team 4 | Integration SDK | AWS Data Platform Integrations |
| Team 5 | Product Onboarding | Command Center Productisation |

The closure wave covers Beta release certification, cross-team integration, defect closure, browser and accessibility validation, backup and restore, HA and restart testing, and release rehearsal.

## Explicit exclusions

Beta 1 excludes production-readiness claims, unrestricted autonomous remediation, unsupported providers, organisation-wide GitHub team provisioning, wholesale page redesign, and capabilities lacking hosted exact-commit certification.

Recommended follow-on branches: `codex/beta-deployment-packaging`, `codex/connector-schema-360-console-v1`, `codex/data-quality-console-v1`, `codex/incident-workbench-v1`, `codex/integration-sdk-v1`, and `codex/product-onboarding-v1`.
