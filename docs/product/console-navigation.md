# Console navigation

Use the workspace switcher or left rail to move among Home, Observe, Investigate, Respond, Integrate, and Admin. The capability list changes with the workspace. Within capabilities such as Streams, Quality, Incidents, and Administration, a third contextual group shows supported nearby pages.

Press `/` or Ctrl/Cmd+K outside a form to open Quick Find. Search workspace names such as `observe`, capability labels such as `stream`, or bounded operational entities. Activity remains in the global header. On narrow screens, open the navigation drawer with the labelled menu button; closing or following a link restores the content view. Sidebar collapse stores only a boolean presentation preference.
