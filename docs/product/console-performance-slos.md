# Console performance SLO targets

The initial product targets are LCP p75 ≤2.5 seconds, INP p75 ≤200 milliseconds, and CLS p75 ≤0.1. Initial usable shell and route-transition baselines require hosted fixed-condition evidence before numeric SLOs are approved. Graph and large-table initialization should be measured as stable capability events in a later shared wrapper.

CI enforces deterministic bundle budgets and selected browser journeys; it does not claim production percentile achievement. Production SLO evaluation requires representative traffic, release segmentation, sufficient sample volume, and documented browser support. Unsupported observers and disabled telemetry are reported as coverage gaps rather than good performance.
