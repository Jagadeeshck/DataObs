# Messaging observability

Messaging supports Kafka, Kinesis, SQS, RabbitMQ, Google Pub/Sub, Azure Event Hubs, Azure Service Bus, and Pulsar presentation. The estate summary shows configured, collecting, stale, and unavailable systems plus coverage on provider cards. The capability matrix explicitly distinguishes Supported, Partial, Not configured, Unavailable, and Not applicable.

Kafka inventory remains available while other provider resource inventories wait for bounded authoritative APIs. Configure Integration is a handoff to the existing Integrations workspace; this Console never collects credentials.
