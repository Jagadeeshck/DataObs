# Operational dashboards

DataObs includes Estate Overview, Data Reliability, Streaming Operations, Incident Operations, Change & Impact, and Integration Operations. They compose authoritative bounded capability evidence and links; they are not a second analytics engine. Private browser views customise registered widgets and layout locally, are not shared, and always apply to the current trusted context. Nearby incident/change presentation makes no causal claim. Forecast is never presented as measured data, impact is never confidence, and missing evidence is never zero.
