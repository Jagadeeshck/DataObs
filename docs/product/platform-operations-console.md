# Platform Operations Console

Authorised platform operators open **Admin → Platform Operations** to inspect fleet, lifecycle inventories, configuration drift and capacity validation. Inventory links open Environment, Installation, Cluster and Tenant 360 metadata views. Tenant 360 offers an explicit **Offboarding preview**, which performs only the authoritative GET preview and never begins deletion.

Lifecycle and health are separate. Unknown evidence remains unknown. A partial-evidence banner identifies unavailable providers while successful sections remain usable. Fleet entity global search is intentionally absent because no bounded server search API exists.
