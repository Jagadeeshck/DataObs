# Platform Supportability

Authorised platform operators can open **Supportability** and **Operational Readiness** under Platform Operations. The overview presents the support profile, separate state hierarchy, diagnostics, configuration fingerprint metadata, maintenance evidence and bounded known issues. The readiness route prioritises the authoritative headline, explicit blockers and gate evidence.

Runbook coverage, certification and support-bundle actions remain visibly unavailable when no public API exists. “No records returned” never claims that no issues exist.
