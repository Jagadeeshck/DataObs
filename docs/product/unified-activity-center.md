# Unified Activity Center v1

Activity answers what changed and where to investigate next without competing with capability-owned state. Incident activity is supported in v1; other audited sources remain excluded until a bounded, tenant-safe summary contract exists. Incident, Case, Workflow and Remediation language stays distinct.

The responsive semantic feed exposes type, capability, timestamp, severity/state, evidence, provenance, actionability, entity kind and Seen/Unseen text. Tabs and filters are keyboard controls; the modal drawer has a labelled dialog, initial close focus, and backdrop close. State never relies on colour alone. Known limitation: My Actions and dashboard widgets are omitted because no principal-scoped bounded action feed or shared aggregate endpoint was audited. The shell therefore shows presence rather than an attention count and causes no hidden provider fan-out.
