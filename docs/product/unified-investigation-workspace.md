# Unified Investigation Workspace v1

Supported anchors are assets, data products, monitors, jobs, runs, pathways and incidents. The workspace presents bounded entity state, quality evaluations/findings, pathway health/established membership, and incident/timeline evidence on a deterministic common timeline. Source provenance and uncertainty are visible. Related evidence means only an authoritative relationship; nearby events are not asserted to be causal. Keyboard users can filter and select timeline rows and use the relationship table without a visual graph.
