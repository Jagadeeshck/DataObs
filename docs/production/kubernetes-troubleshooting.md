# Kubernetes troubleshooting

Inspect `helm status`, events, Deployment conditions, migration Job logs, and container logs with server-side redaction. Probe API `/livez` and `/readyz`, Console `/healthz`, and Collector port 13133. Check Secret names/keys, Elasticsearch TLS CA and permissions, OIDC reachability, NetworkPolicy CIDRs/DNS, image pull authorization and resource pressure. Worker absence may be an intentional disabled value; workers have no Service. Uninstall does not delete external Elasticsearch data.
