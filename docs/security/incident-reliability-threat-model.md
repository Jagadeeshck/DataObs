# Incident reliability threat model

Trusted principal context supplies tenant and environment. Repositories must place both in every query and document identity. Analytics accept only bounded date ranges and allowlisted groupings, never raw DSL. Derived compliance, breach, assignment hashes, exclusions, and objective results are server-owned.

Authorization must separately protect definition mutation and approved exclusion. Source revisions and optimistic concurrency prevent stale workers from replacing newer projections. Cursor values must be signed and scope-bound. Responses must not mix environments or tenants.
