# Security audit events
Security-significant denials, key failures, bootstrap use, escalation protection and IAM mutations append to `logs-dataobs.security-event-default`, within migration 0020's `logs-dataobs.security-event-*` family. Events have bounded identifiers and hashed source/browser values; tokens, headers, claims, passwords, secret references and raw IPs are prohibited. IAM mutations require a successful audit append. Operators configure retention and restricted read access through Elasticsearch lifecycle/security policy.
